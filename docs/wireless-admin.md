# 동구시장 가망고객 관리

- 등록: https://www.ktmns.store/wireless-consult.html
- 관리: https://www.ktmns.store/wireless-admin.html
- 로그인: 기존 admin.html에서 사용하는 Google Sheets 관리자 비밀번호.
- 새 환경변수나 새 저장소 설정은 필요하지 않습니다.

등록은 기존 `/api/consult` → 기존 Google Sheets `create` 흐름을 그대로 사용합니다. 텔레그램 수신처 `-5350656846`도 유지합니다. 관리자 화면은 전용 `/api/wireless-leads`에 POST로 비밀번호를 전달하고, 서버는 기존 Sheets `list` 인증 성공 후 동구시장 무선 상담만 반환합니다. 비밀번호와 고객 목록은 브라우저 저장소에 저장하지 않습니다.

기존 저장소의 스키마를 변경하지 않기 위해 복지할인·요금·메모는 기존 `message`의 라벨 형식에 저장합니다. 메모 앞쪽의 메타데이터만 분리하므로 메모 안의 슬래시와 라벨은 그대로 표시됩니다. 기존 동구시장 무선 상담 기록도 조회됩니다. 이미 삭제되었거나 저장에 실패하고 텔레그램으로만 전달된 기록은 복원하지 않습니다.

기존 접수 API는 텔레그램 전송 후 Sheets 저장을 수행합니다. 네트워크 오류가 나면 저장 여부가 불명확할 수 있으므로 등록 화면은 재등록 전 관리 목록 확인을 안내합니다. 저장 완료 버튼은 고객 내용을 변경할 때까지 비활성화합니다.

배포 시 정적 화면(GitHub Pages)과 Vercel API가 모두 최신 커밋인지 확인하세요. 기능 검증: `node --test tests/wireless-leads.test.js`. 테스트는 외부 통신을 모의 처리하며 실제 고객 데이터나 텔레그램 메시지를 생성하지 않습니다. 운영 비밀번호 로그인과 실제 등록 확인은 권한 있는 직원이 수행합니다.
